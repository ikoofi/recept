# Книга рецептов

Локальная книга рецептов: Flask + SQLite, пересчёт по главному ингредиенту,
печать в DOCX, обмен рецептами через файлы `.json`.

## Для пользователя (Windows)

1. Распаковать `КнигаРецептов.zip` в любую папку.
2. Запустить «Книга рецептов.bat»: откроется браузер, на рабочем столе появится ярлык.
3. Дальше запускать ярлык «Книга рецептов». Выход — кнопка «Выход» в книге.

Рецепты хранятся в `data/recipes.db` рядом с программой.

## Сборка архива для Windows

```bash
./build_windows.sh
```

Скачивает встроенный Python с python.org и библиотеки для Windows, собирает
`dist/КнигаРецептов.zip`. Работает и на Linux.

## Разработка

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python app.py          # http://127.0.0.1:5000, режим отладки
.venv/bin/python launcher.pyw    # как у пользователя: порт 8765 + браузер
```

`RECEPT_DATA` — другая папка для базы, `RECEPT_PORT` — другой порт запускалки.
