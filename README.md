# Книга рецептов

Локальная книга рецептов: Flask + SQLite. Фото, категории, избранное, время и порции,
пересчёт по любому ингредиенту или порциям, меню на неделю, список покупок по отделам
магазина, режим готовки с таймером, печать в DOCX, обмен рецептами через файлы `.json`.

## Для пользователя (Windows)

1. Запустить `КнигаРецептов-Setup.exe` и выбрать папку: права администратора не нужны.
2. Запускать ярлык «Книга рецептов» на рабочем столе. Выход — кнопка «Выход» в книге.

Обновление — тот же установщик в ту же папку, рецепты сохраняются. Вариант без установки:
распаковать `КнигаРецептов.zip` и запустить «Книга рецептов.bat».

Рецепты хранятся рядом с программой: `data/recipes.db` и фото в `data/photos`.

## Сборка архива для Windows

```bash
./build_windows.sh
```

Скачивает встроенный Python с python.org и библиотеки для Windows, собирает
`dist/КнигаРецептов.zip` и установщик `dist/КнигаРецептов-Setup.exe`. Работает и на Linux.

## Сборка APK для Android

Нужны Android SDK в `~/Android/Sdk` (путь задаётся в `android/local.properties`) и Python 3.12.

```bash
cd android && ./gradlew assembleRelease
```

Результат: `android/app/build/outputs/apk/release/app-release.apk`. Код сайта берётся из корня
репозитория, отдельной копии в `android/` нет.

Ключ подписи и пароль лежат в `~/Android/keys` и в git не входят. Без этой папки нельзя выпустить
обновление, которое встанет поверх уже установленного приложения, поэтому храните её копию.

## Разработка

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python app.py          # http://127.0.0.1:5000, режим отладки
.venv/bin/python launcher.pyw    # как у пользователя: порт 8765 + браузер
```

`RECEPT_DATA` — другая папка для базы, `RECEPT_PORT` — другой порт запускалки.
